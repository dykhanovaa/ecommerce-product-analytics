# Исходные данные

Поместите сюда CSV-файлы набора [Retailrocket E-commerce Dataset](https://www.kaggle.com/retailrocket/ecommerce-dataset):

- `events.csv`
- `item_properties_part1.csv`
- `item_properties_part2.csv`
- `category_tree.csv`

Файлы с данными не включены в репозиторий: исходный набор занимает около 1 ГБ. На Kaggle для него указана лицензия CC BY-NC-SA 4.0; перед повторной публикацией данных проверьте условия лицензии. Сами расчеты проекта используют таблицу событий и свойства товаров.
